# SG Pixel Font Collection

The TrueType sources in this directory come from SpicyGame's [SG Font
Collection](https://spicygame.itch.io/fonts), version 6 (June 2026). The
collection contains 19 pixel fonts and is released under the Creative Commons
Zero v1.0 Universal license. The creator states that the fonts may be used for
any purpose, including commercial projects, without attribution.

The game renders these fonts into small monochrome atlases using
[`tools/build-upgrade-font-atlases.py`](../../../tools/build-upgrade-font-atlases.py).
Those generated PNG atlases are the runtime assets under `PyoroGL/Assets/upgrade-fonts/`.
